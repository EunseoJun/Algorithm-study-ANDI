## dfs, bfs 풀이 방법

6. DFS와 BFS 중 어떤 방법이 적합하지?
    
    모든 경우를 탐색하는지, 최단거리를 구하는지 등을 고려하기
    

## DFS와 BFS 중 무엇을 선택해야 할까?

| 문제 조건 | 우선 고려할 방법 |
| --- | --- |
| 연결된 영역의 개수 구하기 | DFS 또는 BFS |
| 모든 가능한 조합 탐색 | DFS / 백트래킹 |
| 최단거리 구하기 (모든 이동 비용이 동일) | BFS |
| 최소 이동 횟수 구하기 | BFS |
| 모든 경로를 끝까지 탐색 | DFS |
| 그래프에 사이클이 있는 경우 | DFS/BFS + 방문 관리 |

void dfs(vector<int> numbers, int target, int idx, int sum)

이렇게 선언ㅎ면 함수를 호출할때마다 벡터 전체를 복사하게 됨 → 비효율 발생

void dfs(vector<int>& numbers, int target, int idx, int sum)

이렇게 하면 벡터를 복사하지 않고 원본을 참조함. (dfs의 경우 재귀 호출하니까 매번 벡터를 복사하면 비효율적임)

void dfs(const vector<int>& numbers, int target, int idx, int sum)

const 는 함수 안에서 원본 벡터를 수정하지 못하도록 막아줌. (numbers 수정할 필요 없으니까)

- tip
    
    ```
    void dfs(int sum)
    ```
    
    이렇게 `int`를 전달할 때는 보통 `&`를 붙이지 않는데,
    
    ```
    void dfs(vector<int>& numbers)
    ```
    
    벡터에는 왜 `&`를 붙일까?
    
    `int`는 복사 비용이 작지만, `vector`는 원소가 많아질수록 복사 비용이 커짐.
    
    그래서 C++ 코딩테스트에서는 `vector`, `string`처럼 데이터가 커질 수 있는 자료형을 읽기만 할 때 `const &`로 전달하는 패턴을 자주 사용함.
    

- 종료 조건 세우기

if (idx == numbers.size()){

if(sum == target) answer++;

return;

}

- 전역 변수로 answer 선언해야 dfs 함수에 인자 넘겨줄 수 있음

## dfs/bfs 기본 템플릿

DFS는 보통 재귀함수, BFS는 queue를 사용함

## 1. DFS 기본 틀 (재귀함수)

```

#include <vector>
using namespace std;

vector<vector<int>> graph;
vector<bool> visited;

void dfs(int node) {
    visited[node] = true;

    for (int next : graph[node]) {
        if (!visited[next]) {
            dfs(next);
        }
    }
}
```

핵심 구조

1. `visited[node] = true` → 현재 노드 방문 처리
2. `for` → 연결된 노드 확인
3. `if (!visited[next])` → 방문하지 않았다면
4. `dfs(next)` → 재귀호출로 다음 노드 탐색

## 2. BFS 기본 틀 (Queue)

```

#include <vector>
#include <queue>
using namespace std;

vector<vector<int>> graph;
vector<bool> visited;

void bfs(int start) {
    queue<int> q;

    q.push(start);
    visited[start] = true;

    while (!q.empty()) {
        int node = q.front();
        q.pop();

        for (int next : graph[node]) {
            if (!visited[next]) {
                visited[next] = true;
                q.push(next);
            }
        }
    }
}
```

핵심 구조

1. `queue<int> q` → 큐 생성
2. `q.push(start)` → 시작 노드 삽입
3. `while (!q.empty())` → 큐가 빌 때까지 탐색
4. `q.front()` / `q.pop()` → 현재 노드 꺼내기
5. `visited[next] = true` / `q.push(next)` → 다음 노드 방문 예약

## 3. DFS와 BFS 기본 코드 비교

| DFS | BFS |
| --- | --- |
| 재귀함수 | queue |
| 깊이 우선 탐색 | 너비 우선 탐색 |
| `dfs(next)` | `q.push(next)` |
| 호출 스택 이용 | 큐 이용 |
| 방문 시점에 `visited` 처리 | 큐에 넣을 때 `visited` 처리 |
|  |  |
1. 네트워크
- 문제
    
    코딩테스트 연습 - 네트워크
    
- 풀이 코드
    
    ```jsx
    #include <string>
    #include <vector>
    
    using namespace std;
    
    void dfs(int v, int n,
             const vector<vector<int>>& computers,
             vector<bool>& visited) {
    
        visited[v] = true;
    
        for (int i = 0; i < n; i++) {
            if (computers[v][i] == 1 && !visited[i]) {
                dfs(i, n, computers, visited);
            }
        }
    }
    
    int solution(int n, vector<vector<int>> computers) {
        int answer = 0;
        vector<bool> visited(n, false);
    
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                dfs(i, n, computers, visited);
                answer++;
            }
        }
    
        return answer;
    }
    
    ```
    
     visited 배열과 현재 상황을 알 수 있는 computers 배열 생성
    
    computers 배열은 i번 컴퓨터와 j번 컴퓨터가 연결되어 있는지를 나타냄
    
    1. 방문 처리
    
    ㅇ아직 방문하지 않은 컴퓨터라면 Dfs 실행.
    
    dfs를 통해 해당 컴퓨터랑 이어져 있는 모든 컴퓨터 방문처리.
    
    dfs가 꿑나면 answer 하나 증가시킴
    
    ㄷ다음 컴퓨터 하면서 혹시 방문했다면 스킵
    
    **방문하지 않은 컴퓨터 발견 → DFS 시작 → 현재 컴퓨터 방문 처리 → 연결된 방문하지 않은 컴퓨터를 재귀적으로 탐색 → DFS 종료 → 네트워크 개수 증가 → 다음 미방문 컴퓨터 탐색**
    
    여기서 꼭 구분해야 하는 건 **dfs()는 연결된 컴퓨터를 모두 방문하는 역할이고, solution()은 DFS를 새로 시작하는 횟수를 세는 역할.**

1. n + 1 카드게임 (2024, Lv.3))

매 라운드마다 최대 n개의 숫자를 확인하고, 라운드 수는 최대 n/3개이므로 시간 복잡도는 o(n^2)

n이 천개 이하면 통과가능

그리디로 풀기

실제 게임에서 카드를 무작정 버리면 나중에 필요한 카드를 잃어버릴 수 있음 → 그리디 알고리즘

**① 새로 등장한 카드를 모두 후보에 기록한다.**

**② 당장 필요한 카드 조합 중 동전이 가장 적게 드는 조합을 사용한다.**

**③ 나중에 사용하게 된 후보 카드는 실제로는 처음 등장했을 때 구매해 두었다고 해석한다.**

**④ 최종 동전 사용량이 초기 동전 수를 넘지 않도록 관리한다.**

나중에 8이나 12가 필요할 수도 있는데 왜 버려! 라는 문제를 해결하기 위해 pending이라는 후보 배열을 사용함.

```
for(int j=1;j<=n/2;j++){
// j와 더해서 n+1이 되는 카드 번호 찾기
int other = n + 1 - j;

// 두 카드를 모두 가지고 있다면
if (hand[j] && hand[other]) {

    // 두 카드를 제출했으므로 보유 상태 해제
    hand[j] = false;
    hand[other] = false;

    // 이번 라운드 성공
    success = true;

    // 카드 두 장을 찾았으므로 탐색 종료
    break;
}
}
```

**①** 1번 카드부터 확인한다.

**②** 그 카드와 합쳐서 n + 1이 되는 짝을 계산한다.

**③** 두 카드를 모두 가지고 있는지 확인한다.

**④** 두 카드가 모두 있으면 제출하고, 가지고 있던 카드 목록에서 제거한다.

**⑤** 이번 라운드를 성공했다고 표시하고 반복문을 종료한다.

```jsx
#include <vector>
using namespace std;

int solution(int coin, vector<int> cards) {
    int n = cards.size();
    int answer = 1;

    vector<bool> hand(n + 1, false);
    vector<bool> pending(n + 1, false);

    for (int i = 0; i < n / 3; i++) {
        hand[cards[i]] = true;
    }

    for (int i = n / 3; i < n; i += 2) {

        pending[cards[i]] = true;
        pending[cards[i + 1]] = true;

        bool success = false;

        // 동전 0개
        for (int j = 1; j <= n / 2; j++) {
            int other = n + 1 - j;

            if (hand[j] && hand[other]) {
                hand[j] = false;
                hand[other] = false;

                success = true;
                break;
            }
        }

        // 동전 1개
        if (!success && coin >= 1) {
            for (int j = 1; j <= n; j++) {
                int other = n + 1 - j;

                if (hand[j] && pending[other]) {
                    hand[j] = false;
                    pending[other] = false;

                    coin--;
                    success = true;
                    break;
                }
            }
        }

        // 동전 2개
        if (!success && coin >= 2) {
            for (int j = 1; j <= n / 2; j++) {
                int other = n + 1 - j;

                if (pending[j] && pending[other]) {
                    pending[j] = false;
                    pending[other] = false;

                    coin -= 2;
                    success = true;
                    break;
                }
            }
        }

        if (!success) {
            break;
        }

        answer++;
    }

    return answer;
}
```
